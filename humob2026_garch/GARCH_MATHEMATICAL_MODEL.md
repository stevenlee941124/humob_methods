## 1️⃣ 第一支柱：多時期基準錨點與單調三次 Hermite 樣條中軸線 B(t)

### 1.1 四大時期穩態錨點提取 (Multi-Period Anchor Extraction)
為了鎖定全年 366 天時間跨度內的宏觀復原趨勢，模型在各關鍵歷史時期提取統計穩態錨點：

1. **震前常態基準錨點 (y_pre)**：
   > **y_pre = Mean( { y(t) | t < 2024-01-01 且 t ∉ ExcludedDates } )**
   * *物理意義*：地震發生前（2023/11/01 ~ 2023/12/31）能登半島的常態人流水平。

2. **1 月震後衝擊錨點 (y_jan)**：
   > **y_jan = Mean( { y(t) | 2024-01-15 ≤ t ≤ 2024-02-01 且 t ∉ ExcludedDates } )**
   * *物理意義*：1/1 地震發生後，人流斷崖式下跌或避難湧入後的「第一階段受災穩態」。

3. **4~6 月復原期基準錨點 (y_post)**：
   > **y_post = Mean( { y(t) | 2024-04-01 ≤ t ≤ 2024-06-30 且 t ∉ ExcludedDates } )**
   * *物理意義*：盲區結束後春季重建與復原期的實際人流水平。

4. **8~10 月後期穩定期錨點 (y_end)**：
   > **y_end = Mean( { y(t) | 2024-08-01 ≤ t ≤ 2024-10-31 且 t ∉ ExcludedDates } )**
   * *物理意義*：災後下半年的長期重建穩態水準。

---

### 1.2 單調三次 Hermite 樣條方程 (Monotone Cubic Hermite Spline)
定義 7 個關鍵時間節點向量 T 與對應的目標水平向量 Y：
* **時間節點向量**：
  > **T = [ t_start, t_2023-12-31, t_2024-01-15, t_2024-02-01, t_2024-04-01, t_2024-05-01, t_end ]**
* **目標數值向量**：
  > **Y = [ y_pre, y_pre, y_jan, y_jan, y_post, y_post, y_end ]**
* **邊界一階導數約束 (Zero Slopes)**：
  > **dY/dt = [ 0, 0, 0, 0, 0, 0, 0 ]**

#### 為什麼選用 Hermite 樣條而不是一般多項式？
一般高階多項式插值在節點之間會發生**龍格現象（Runge's Phenomenon）**，產生虛假的波浪過衝；而將 Hermite 樣條的一階導數強制鎖定為 0，能夠保證在任意區間 [T(k), T(k+1)] 內呈現嚴格的**單調平滑過渡（C¹ 連續）**。

在區間 [T(k), T(k+1)] 內，定義標準化時間參數：
> **u = ( t - T(k) ) / ( T(k+1) - T(k) ) ,  u ∈ [0, 1]**

三次 Hermite 基函數如下：
* **h₀₀(u) = 2u³ - 3u² + 1**
* **h₁₀(u) = u³ - 2u² + u**
* **h₀₁(u) = -2u³ + 3u²**
* **h₁₁(u) = u³ - u²**

最終宏觀平滑中軸線方程：
> **B(t) = max( 0.01,  h₀₀(u) · Y(k) + h₀₁(u) · Y(k+1) )**

## 2️⃣ 第二支柱：日曆去污染與 7 天週週期連續載波 ψ(τ)

### 2.1 日曆去污染殘差提取 (Residual Extraction)
日本國定假日（如天皇誕生日、元旦）居民不上班不通勤，若將其混入計算會嚴重拉低平日均值。因此在計算 7 天標準作息時，**嚴格剔除所有日本國定假日與假日前夕**：
> **r(t) = y(t) - B(t) ,  ∀ t ∉ ( Japan_Holidays ∪ Eve_Holidays ∪ ExcludedDates )**

### 2.2 星期均值提純與標準化 (Z-Score Normalization)
計算週一至週日（d ∈ {0, 1, ..., 6}）的純淨殘差均值：
> **r̄(d) = ( 1 / |S(d)| ) · Σ r(t)**

進行 Z-Score 無量綱標準化，消除量綱影響：
> **ψ(d) = ( r̄(d) - Mean(r̄) ) / ( Std(r̄) + 10⁻⁶ )**

### 2.3 連續週期三次插值函數 ψ(τ)
將 7 天離散向量複製 5 週（35 天），以三次樣條包裝成連續函數：
> **ψ(τ) = CubicSpline( τ , Tile(ψ(0..6), 5) )**

### 2.4 震後作息相位延遲衰減 (Phase Shift Decay)
地震後民眾作息混亂、通勤時間推遲，隨著時間推移呈現**指數衰減回歸常態**：
> **φ(t) = 0.35 · exp( -0.02 · t )**
> 
> **τ(t) = DOW_t + φ(t) + 14.0**

## 3️⃣ 第三支柱：GARCH(1,1) 動態條件異方差波動率

### 3.1 振幅規模估計 (Amplitude Scale)
基於 4~6 月觀測期的 10% 與 90% 分位數差值估計波動尺度：
> **A = ( Percentile₉₀(y_post) - Percentile₁₀(y_post) ) / 2**  
> *(若樣本數不足 10 天，則設定為 A = 0.35 · y_post)*

### 3.2 GARCH(1,1) 參數設計與推導
* **衝擊反應係數 (Shock Sensitivity)**：α = 0.25
* **波動持續係數 (Persistence)**：β = 0.65
* **長期平穩方差 (Long-term Variance)**：σ_long² = (0.5 · A)²
* **常數項 (Intercept) 推導**：
  依據 GARCH 平穩條件 σ_long² = ω / (1 - α - β)：
  > **ω = σ_long² · ( 1 - α - β ) = (0.5 · A)² · 0.10**
* **盲區初期條件方差 (Initial Variance at Gap Start)**：
  > **σ(0)² = ( 0.8 · A )²**

### 3.3 盲區 90 天條件方差動態差分遞推
在盲區 90 天期間（無外部即時觀測輸入），條件方差自動依 GARCH 動態差分方程平滑演化：
> **σ(t)² = ω + β · σ(t-1)²**
> 
> **σ(t) = √( max( 10⁻⁴, σ(t)² ) )**

*物理表現*：震後 2 月維持較大的人流波動幅，並隨時間推進平滑收斂至長期穩態振幅 σ_long。

## 4️⃣ 第四支柱：日本國定假日狀態機與出遊增益修正

針對 90 天盲區內的特殊日曆事件（如 4/29 昭和之日、4/28 假日前夕出遊）：

1. **國定假日行為輪廓映射**：
   若 t 為國定假日，將其等效星期強制映射為週日輪廓（抑制上班通勤人流）：
   > **DOW_effective(t) = 6  (若 is_holiday(t) == True)**
2. **假日前夕出遊增益 (Holiday Eve Surge)**：
   若 t 為國定假日前一天，居民提前出遊或採買，給予正向增益修正：
   > **Mod_hol(t) = 0.15 · A  (若 is_holiday_eve(t) == True)**

## 5️⃣ 雙軌分層合成總公式 (Hierarchical Flow Synthesis)

### 🅰️ 對角線停留流量 (Diagonal Stay Flow: src == dst)
市中心網格停留流量佔總量 90% 以上（均值 26.57 人），採用四支柱動態波形合成：
> **pred_flow(t) = max( 0,  B(t) + σ(t) · ψ( DOW_effective(t) + 14.0 ) + Mod_hol(t) )**

### 🅱️ 非對角線跨區流動 (Off-Diagonal Flow: src != dst)
全域 217.7 萬個網格對中，99% 以上真實流量為 0。為避免在零流量對注入假性波動噪聲，採用宏觀平滑中軸線：
> **pred_flow_{u,v}(t) = B_{u,v}(t)**

---

## 6️⃣ 稀疏噪聲過濾門檻 (> 0.1 人截斷機制)

為了防止微小浮點小數（如 0.0215、0.0482 人）污染矩陣稀疏性：

```
ŷ(t) = pred_flow(t)    (若 pred_flow(t) > 0.1 人)
ŷ(t) = 0.0             (若 pred_flow(t) ≤ 0.1 人)
```

此機制大幅縮減 TSV 輸出體積，使稀疏矩陣更加純淨。

官方評測標準使用 4 月份 28 天有效觀測之對稱加權正規化均方根誤差：

1. **對角線停留誤差 (N_diag = 1,476，官方常數分母 = 26.57)**：
   > **RMSE_diag = √( (1 / 1476) · Σ (y(g,g) - ŷ(g,g))² )**  
   > **NRMSE_diag = RMSE_diag / 26.57**

2. **非對角線跨區誤差 (N_off = 2,177,100，官方常數分母 = 0.0176)**：
   > **RMSE_off = √( (1 / 2177100) · Σ (y(u,v) - ŷ(u,v))² )**  
   > **NRMSE_off = RMSE_off / 0.0176**

3. **綜合指標 (Combined NRMSE)**：
   > **Combined NRMSE = 0.5 · ( NRMSE_diag + NRMSE_off )**
