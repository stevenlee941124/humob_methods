## 🧭 模型整體架構總覽 (Mathematical Overview)

預測目標為能登半島地震後 **90 天盲區時段**（t ∈ [92, 181]，對應 2024/02/01 ~ 2024/04/30）的全域 OD 流量矩陣：

```
                    ┌──────────────────────────────────────────────────┐
                    │               OD 流量預測 ŷ(t)                   │
                    └────────────────────────┬─────────────────────────┘
                                             │
                  ┌──────────────────────────┴──────────────────────────┐
                  ▼                                                     ▼
      【對角線停留流量 (src == dst)】                         【非對角線跨區流動 (src != dst)】
    ──────────────────────────────────────                 ──────────────────────────────────────
      ŷ(t) = B(t) + σ_t · ψ(τ) + Mod_hol                     ŷ(t) = B(t)  (宏觀平滑中軸線)
      • 三次 Hermite 樣條中軸線 B(t)                         • 避免對 217.7 萬稀疏零流量對
      • 去污染 7 天週載波 ψ(τ)                                注入虛假波動雜訊
      • GARCH(1,1) 條件異方差 σ_t²
      • 假日與出遊前夕修正 Mod_hol
```

## 1️⃣ 第一支柱：多時期錨點與單調三次 Hermite 樣條中軸線 B(t)

### 1.1 錨點提取 (Multi-Period Anchor Extraction)
為了鎖定全年宏觀的災後復原趨勢，模型在全年 366 天時間序列中選取 4 個關鍵時期的穩態錨點：

1. **震前基準錨點 (y_pre)**：
   > **y_pre = Mean( { y(t) | t < 2024-01-01 且 t ∉ ExcludedDates } )**
2. **1 月震後衝擊錨點 (y_jan)**：
   > **y_jan = Mean( { y(t) | 2024-01-15 ≤ t ≤ 2024-02-01 且 t ∉ ExcludedDates } )**
3. **4~6 月復原期錨點 (y_post)**：
   > **y_post = Mean( { y(t) | 2024-04-01 ≤ t ≤ 2024-06-30 且 t ∉ ExcludedDates } )**
4. **8~10 月後期穩定錨點 (y_end)**：
   > **y_end = Mean( { y(t) | 2024-08-01 ≤ t ≤ 2024-10-31 且 t ∉ ExcludedDates } )**

### 1.2 節點時間與樣條插值方程 (Cubic Hermite Spline)
定義 7 個時間節點向量 T 與對應之目標水平向量 Y：
* **時間節點**：
   > **T = [ t_start, t_2023-12-31, t_2024-01-15, t_2024-02-01, t_2024-04-01, t_2024-05-01, t_end ]**
* **目標數值**：
   > **Y = [ y_pre, y_pre, y_jan, y_jan, y_post, y_post, y_end ]**
* **一階導數邊界條件 (Slopes)**：
   > **dY/dt = [ 0, 0, 0, 0, 0, 0, 0 ]**（保證各時期平穩過渡，杜絕高階多項式之龍格震盪 Runge Phenomenon）

在任意區間 [T_k, T_{k+1}] 內，標準化時間參數為：
> **u = (t - T_k) / (T_{k+1} - T_k) ,  u ∈ [0, 1]**

三次 Hermite 樣條基函數如下：
* **h₀₀(u) = 2u³ - 3u² + 1**
* **h₁₀(u) = u³ - 2u² + u**
* **h₀₁(u) = -2u³ + 3u²**
* **h₁₁(u) = u³ - u²**

最終宏觀平滑中軸線方程：
> **B(t) = max( 0.01,  h₀₀(u) · Y_k + h₀₁(u) · Y_{k+1} )**

## 2️⃣ 第二支柱：日曆去污染與 7 天週週期載波 ψ(τ)

### 2.1 去除假日干擾之殘差提取 (Residual Extraction)
為了避免日本國定假日（如元旦、成人之日、天皇誕生日）污染常態的星期規律，首先剔除所有假日：
> **r(t) = y(t) - B(t) ,  ∀ t ∉ ( Japan_Holidays ∪ ExcludedDates )**

### 2.2 星期均值載波提純 (Day-of-Week Averaging)
計算星期一至星期日（d ∈ {0, 1, ..., 6}）的純淨殘差均值：
> **r̄_d = ( 1 / |S_d| ) · Σ_{t ∈ S_d} r(t)**

### 2.3 標準化載波 (Z-Score Normalization)
計算 7 天載波標準差 σ_r 並進行無量綱標準化：
> **ψ_d = ( r̄_d - Mean(r̄) ) / ( Std(r̄) + 10⁻⁶ )**

### 2.4 連續週期三次插值函數 ψ(τ)
將 7 天離散向量循環複製 5 週（共 35 天），以三次樣條建立連續函數 ψ(τ)：
> **ψ(τ) = CubicSpline( τ , Tile(ψ_{0..6}, 5) )**

### 2.5 震後相位衰減修正 (Phase Shift Decay)
地震發生後，居民通勤與作息節奏出現相位延遲，隨著時間推移呈指數衰減回歸常態：
> **φ(t) = 0.35 · exp( -0.02 · t )**
> 
> **τ(t) = DOW_t + φ(t) + 14.0**

## 3️⃣ 第三支柱：GARCH(1,1) 動態條件異方差波動率

### 3.1 振幅規模估計 (Amplitude Scale)
基於 4~6 月觀測期的 10% 與 90% 分位數估計動態振幅：
> **A = ( Percentile₉₀(y_post) - Percentile₁₀(y_post) ) / 2**  
> *(若樣本數不足 10 天，則設定為 A = 0.35 · y_post)*

### 3.2 GARCH(1,1) 參數設定
* **衝擊反應係數 (Shock Sensitivity)**：α = 0.25
* **波動持續係數 (Persistence)**：β = 0.65
* **長期平穩方差 (Long-term Variance)**：σ_long² = (0.5 · A)²
* **常數項 (Intercept)**：
  > **ω = σ_long² · ( 1 - α - β ) = (0.5 · A)² · 0.10**
* **震後初始條件方差 (Initial Variance at Gap Start)**：
  > **σ₀² = ( 0.8 · A )²**

### 3.3 盲區 90 天條件方差動態遞推 (Recursive Variance Propagation)
在盲區 90 天期間（無外部新觀測衝擊），條件方差依 GARCH 差分方程遞推演化：
> **σ_t² = ω + β · σ_{t-1}²**
> 
> **σ_t = √( max( 10⁻⁴, σ_t² ) )**

此機制確保震後初期維持較高波動幅，隨後平滑收斂至長期穩態振幅 σ_long。

## 4️⃣ 第四支柱：日本國定假日與出遊前夕增益修正

針對 90 天盲區內的特殊日曆事件（如 4/29 昭和之日、4/28 假日前夕）：

1. **國定假日行為輪廓映射**：
   若 t 為國定假日，將其等效星期強制映射為週日輪廓（抑制上班通勤人流）：
   > **DOW_effective(t) = 6  (若 is_holiday(t) == True)**
2. **假日前夕出遊增益 (Holiday Eve Surge)**：
   若 t 為國定假日前一天，居民提前出遊或採買，給予增益修正：
   > **Mod_hol(t) = 0.15 · A  (若 is_holiday_eve(t) == True)**

## 5️⃣ 雙軌分層合成總公式 (Hierarchical Synthesis)

### 🅰️ 對角線停留流量 (Diagonal Stay Flow: src == dst)
> **ŷ(t) = max( 0,  B(t) + σ_t · ψ( DOW_effective(t) + 14.0 ) + Mod_hol(t) )**

### 🅱️ 非對角線跨區流動 (Off-Diagonal Flow: src != dst)
全域 217.7 萬個網格對中，99% 以上真實流量為 0。為防止在微小稀疏路線注入假性波動噪聲，採用宏觀平滑中軸線：
> **ŷ_{u,v}(t) = B_{u,v}(t)  (僅在該路線屬於活躍集且 B(t) > 0.01 時輸出，否則為 0)**

## 6️⃣ 官方評估指標與對比成績 (Evaluation Metric)

官方評測標準使用 4 月份 28 天有效觀測之對稱加權正規化均方根誤差：

1. **對角線停留誤差 (N_diag = 1,476)**：
   > **RMSE_diag = √( (1 / 1476) · Σ_{g=1}^{1476} (y_g,g - ŷ_g,g)² )**  
   > **NRMSE_diag = RMSE_diag / 26.57**

2. **非對角線跨區誤差 (N_off = 2,177,100)**：
   > **RMSE_off = √( (1 / 2177100) · Σ_{u ≠ v} (y_{u,v} - ŷ_{u,v})² )**  
   > **NRMSE_off = RMSE_off / 0.0176**

3. **綜合指標 (Combined NRMSE)**：
   > **Combined NRMSE = 0.5 · ( NRMSE_diag + NRMSE_off )**
