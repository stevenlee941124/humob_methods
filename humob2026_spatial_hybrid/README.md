# 🔮 HuMob 2026: 三層物理融合模型 (Spatial-Temporal Hybrid Gated Diffusion)

本資料夾包含了 **HuMob 2026 能登半島災後人口流動預測挑戰賽** 的最終旗艦模型：**「零值真實感知 Baseline + 自適應規律度通勤載波 $\psi$ + 2D 空間地理擴散張量」三層物理融合架構**。

該模型在官方四月份真實驗證集上達到了 **Combined NRMSE `0.31146`** 的突破性優異成績（比純 Diffusion 大幅降低 **-0.160**）！

## 📖 1. 原始資料 (Raw Data) 詳解

### 1.1 競賽背景與時間跨度
- **資料檔案**：`data/raw/humob2026-dataset.tsv`
- **時間跨度**：2023 年 11 月 1 日 至 2024 年 10 月 31 日，共 **366 天**（包含閏年 2024/02/29）。
  - **重大歷史事件**：**2024 年 1 月 1 日 能登半島芮氏規模 7.6 強震**。地震造成道路損毀與避難撤離，全區人流在 1 月初斷崖式崩跌至全年最低點，隨後展開長達數月的應急搶通與漸進復甦。
  - **90 天盲區 (Blind Gap)**：**2024 年 2 月 1 日 至 2024 年 4 月 30 日**（所有參賽模型需預測這 90 天全域所有 OD 路線人流）。
  - **官方驗證集 (Ground Truth)**：**2024 年 4 月 1 日 至 2024 年 4 月 30 日**（共 28 天有效評測日，排除 4/8 與 4/25 異常維護日）。

### 1.2 網格地理系統 (Spatial Grid Coordinate)
- 地理空間被劃分為能登半島 $70 \times 100$ 的 2D 網格矩陣：
  - 網格編號：`X_Y`（$X \in [1, 70]$，$Y \in [1, 100]$）。
  - 外部區域：`-1_-1`（代表進出能登半島以外的全日本外部流動）。

### 1.3 原始資料格式 (TSV Nested Dictionary Format)
原始 TSV 每行記錄一個日期的全域 OD 流動巢狀字典：
```tsv
20231101	{'41_47': {'41_47': 620.5, '21_60': 15.2, '-1_-1': 45.0}, '10_23': {'10_23': 85.0}}
```
- **停留流動 (Diagonal Flow)**：起點等於終點（如 `41_47 -> 41_47`），代表留在該網格內的人口活動。
- **跨區流動 (Off-Diagonal Flow)**：起點不等於終點（如 `41_47 -> 21_60`），代表跨網格遷移/通勤。
- **稀疏性特徵**：全域共有 **15,129 條活躍 OD 路線**，其中超低流量/散粒噪聲路線佔 **33.5% (5,074 條)**。

### 1.4 官方評測指標 (Official NRMSE)
官方採用正規化均方根誤差 (Normalized RMSE)：
\[
\text{NRMSE}_{\text{diag}} = \frac{\text{RMSE}_{\text{diag}}}{26.57}, \quad \text{NRMSE}_{\text{off}} = \frac{\text{RMSE}_{\text{off}}}{0.0176}
\]
\[
\text{Combined NRMSE} = 0.5 \times \text{NRMSE}_{\text{diag}} + 0.5 \times \text{NRMSE}_{\text{off}}
\]

## 🏛️ 2. 三層物理融合模型架構 (The 3-Layer Physics Paradigm)

最終合成公式如下：
\[
\hat{Y}_i(t) = \max\left(0.0, \; B_i(t) + G_i \cdot \psi_i(\text{DOW}_t + \phi_t) \cdot \sigma_i^{\text{weekly}} + z_i(t) \cdot \sigma_i^{\text{spatial}}\right)
\]

```
                  ┌───────────────────────────────────────────────────────────┐
                  │ 【Layer 1】 宏觀物理中軸 B_i(t)                            │
                  │   • 零值真實感知 (Zero-Aware)                              │
                  │   • 震後首週 (1/2~1/7) 波谷鎖定                            │
                  │   • 排除 5/1~5/6 日本黃金週連假污染 (採樣 5/7~5/21 正常日) │
                  │   • 對數飽和復甦曲線 + 全域 C^1 平滑高斯濾波               │
                  └─────────────────────────────┬─────────────────────────────┘
                                                │ (+)
                  ┌─────────────────────────────▼─────────────────────────────┐
                  │ 【Layer 2】 確定性通勤載波 G_i · ψ_i(DOW_t + φ_t) · σ_temp │
                  │   • 規律度指標量化 S_reg = 0.5·r_7 + 0.5·R^2_weekly       │
                  │   • 自適應門控 G_i ∈ [0, 1]：規律網格全開、低規律網格歸零  │
                  │   • 消除高頻隨機毛刺，提供純淨 7 天通勤齒輪                │
                  └─────────────────────────────┬─────────────────────────────┘
                                                │ (+)
                  ┌─────────────────────────────▼─────────────────────────────┐
                  │ 【Layer 3】 2D 空間地理擴散殘差場 S_spatial(x, y, t)      │
                  │   • 4 通道 2D 空間張量 (70 × 100 網格)                     │
                  │   • 2D ResBlock + Spatial Attention U-Net                  │
                  │   • 捕捉相鄰網格空間牽引、災後空間擴散與區域外溢           │
                  └─────────────────────────────┬─────────────────────────────┘
                                                │
                                                ▼
                  ┌───────────────────────────────────────────────────────────┐
                  │ 【Layer 4】 超低流量前置分離與稀疏分位過濾 (Sparsity Floor)│
                  │   • 超低流量 (P_act < 0.20 或 均值 < 0.40人)：100% 貼 0.0  │
                  │   • 低於 (1 - P_act) 分位數天數自然沉降至 0.0              │
                  │   • 0-Floor 物理自然截斷，絕無懸浮與單日暴走               │
                  └───────────────────────────────────────────────────────────┘
```

## 🚀 4. 一鍵端到端執行指南

### 步驟 1：執行完整五步融合流水線
在專案根目錄下執行：
```powershell
python humob2026_spatial_hybrid/run_full_pipeline.py
```
執行過程將自動完成：
1. **Step 1 (10s)**：提取 15,129 條 OD 路線時序。
2. **Step 2 (58s)**：計算 366 天無縫 Baseline 與自適應規律度門控。
3. **Step 3 (26s)**：計算去中軸/去載波殘差並投影至 2D 空間張量。
4. **Step 4 (207s)**：在 GPU 上訓練 2D Spatial U-Net (120 epochs)。
5. **Step 5 (51s)**：執行 DDIM 採樣、三層合成解碼、超低流量前置分離與官方評測。

### 步驟 2：啟動互動式視覺化儀表板
```powershell
streamlit run humob2026_spatial_hybrid/app_dashboard.py --server.port 8503
```
瀏覽器開啟：`http://localhost:8503`
